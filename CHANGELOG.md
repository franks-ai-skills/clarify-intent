# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/). Keep the version in
`.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json` in sync.

## [1.0.0] - 2026-11-03

### Added

- `clarify-intent` skill: decision test for when to ask, investigate-first
  rule, question format with options and recommendations, handling for
  unattended runs and subagents, and anti-patterns.
- Claude Code plugin and single-plugin marketplace manifests.
- Behavioral eval suite covering both should-ask and should-not-ask cases.
