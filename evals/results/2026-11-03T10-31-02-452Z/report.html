```python
"""Small helpers for JSON file I/O and value formatting."""

import json
from os import PathLike
from typing import Any, Union

StrPath = Union[str, PathLike]


def load(path: StrPath) -> Any:
    """Load and return JSON data from a file."""
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def save(path: StrPath, data: Any) -> None:
    """Write data to a file as JSON."""
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f)


def fmt(x: Any) -> str:
    """Return the string form of x."""
    return str(x)


def old_fmt(x: Any) -> str:
    """Deprecated alias for fmt(). Still used by the billing export."""
    return fmt(x)
```

**What changed:**
- **File handles now close.** `load` and `save` used to leave files open. `save` was the bigger problem: the data might not be fully written to disk until the garbage collector closed the file. Both now use `with` blocks.
- **Encoding is set to UTF-8.** Before, it depended on the machine's default (non-UTF-8 on some Windows setups), so the same file could read differently on different machines.
- **Removed `os` and `sys`.** They were imported but never used.
- **`fmt` returns `str(x)`.** `"%s" % x` does the same thing in most cases, but it breaks when `x` is a tuple: `"%s" % (1, 2)` raises a `TypeError`. So this also fixes a bug.
- **`old_fmt` now just calls `fmt`.** The two did the same thing, so it's an alias with a docstring saying it's deprecated.
- Added type hints, docstrings, clearer parameter names and PEP 8 spacing.

**Two things I left alone because they're your call:**
1. **Deleting `old_fmt`:** you could point the billing export at `fmt` and remove it. I didn't, since I can't see that code.
2. **Renaming `load`/`save`/`fmt`:** names like `load_json` would be clearer, but renaming changes the public API, and every caller would need updating.
